# BlueMap Minimap ダウンロード

Minecraft **26.3**用は[RC.7のリリースページ](https://github.com/moyokurumi/bluemap-minimap/releases/tag/v0.1.0-rc.7)から、
**`bluemap-minimap-0.1.0-rc.7.jar`**をダウンロードしてください。

[日本語の導入・設定手順](setup-ja.md)に、入れ替え方法、Mod Menu対応、地図の自動検出、
見つからない場合の設定方法をまとめています。特定サーバー専用ではない汎用版です。

26.2では26.2用ビルドを使用してください。
[以前のリリース一覧](https://github.com/moyokurumi/bluemap-minimap/releases)と、
[旧RC.1の保存用手順](https://github.com/moyokurumi/bluemap-minimap/blob/v0.1.0-rc.4/docs/download-ja.md)も参照できます。
