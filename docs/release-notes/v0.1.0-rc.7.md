# v0.1.0-rc.7 — Minecraft 26.3

Beta/release candidate for **Minecraft Java Edition 26.3**, **Fabric Loader
0.19.5+**, and **Java 25**. RC.7 is not a Minecraft 26.2 build.

## Download and install / 導入

Download **[bluemap-minimap-0.1.0-rc.7.jar](https://github.com/moyokurumi/bluemap-minimap/releases/download/v0.1.0-rc.7/bluemap-minimap-0.1.0-rc.7.jar)**.
Close Minecraft, move the older mod JAR out of `mods`, and install this JAR in your
26.3 Fabric profile. Keep your existing configuration. Do not install source JARs
or source ZIPs. [日本語の詳しい導入・設定手順](../setup-ja.md)

Minecraft 26.3用です。Minecraftを終了して旧JARを退避し、新しいJARを`mods`へ入れてください。
設定はそのまま引き継げます。26.2にはRC.7を入れず、従来の26.2用ビルドを使ってください。

## Changes

- Target Minecraft 26.3 and Fabric Loader 0.19.5.
- Compile optional Mod Menu integration against 21.0.0 (the 26.3 release).
- Preserve RC.6's generic server discovery, per-server setup, Japanese/English UI,
  existing profiles, HUD options, and optional Mod Menu settings entrypoint.
- No specific game-server address or BlueMap URL is built into this release.
- No Java implementation changes were needed for this port.

For users upgrading from GitHub RC.4: this release also adds the generic setup and
Mod Menu integration introduced in RC.5/RC.6. If automatic discovery cannot identify
your map, open **Esc → BlueMap Minimap → Server setup** (or Configure in Mod Menu),
enter the public BlueMap root URL, load the maps, and choose your current world's map.

Mod Menu is optional. When installed, use its own 26.3-compatible dependencies
(Fabric API and Placeholder API). BlueMap Minimap itself requires neither.

## Validation

2026-10-12: Temurin 25.0.4.1, Gradle 9.5.1, Loom 1.17.7.

- `test build`: **125 tests passed**, zero failures, errors, or skipped tests.
- Packaged client linkage without Mod Menu, and the real Mod Menu 21.0.0 API
  entrypoint/factory invocation, passed.
- An isolated Fabric Loader 0.19.5 client prelaunch loaded the actual Minecraft
  26.3 classes and applied all three required mixins: Minecraft (tick/close), HUD,
  and PauseScreen. Mixin audit passed. The test exited before graphics startup.
- Binary and sources are inspected for server-specific addresses and local state.

**Real Minecraft GUI/HUD rendering, live-server transitions, and interaction with
Sodium/Iris/Distant Horizons/Vivecraft remain unverified.** This is a prerelease;
the prelaunch and automated checks do not establish graphical acceptance.
