# v0.1.0-rc.6 — Generic server setup

Uploaded to [Modrinth](https://modrinth.com/mod/bluemap-minimap/version/Dq9K5I3n)
as beta on 2026-10-09. The project was submitted for review with Unlisted visibility
selected; approval is pending. Not uploaded to GitHub Releases.

## Changes

- Removed the server-specific activation policy and built-in connection profiles.
- Restored bounded discovery with public/private suffix boundaries and exact-host
  HTTP 8100 fallback. The runtime does not use reverse DNS.
- Added Japanese/English setup: server address, root URL, asynchronous map listing,
  per-dimension map selection, and global discovery toggle. Available through the
  pause menu and optional Mod Menu.
- Separated endpoint discovery from map selection. Unknown worlds, ambiguous names,
  and missing explicit maps hide the HUD and display a setup status.
- Kept saved profiles, display preferences, and the existing first-save backup.
- Added response-body deadlines for stalled discovery responses, and rejected URL
  credentials, query strings, and fragments.
- Retained the RC.5 Mod Menu integration and in-mod icon.

## Validation

- Temurin 25.0.4.1 / Gradle 9.5.1: `--offline --no-daemon test build` passed.
- 125 tests passed, zero failures/errors/skips. Server-specific assertions were
  replaced with generic migration, form validation, and map-selection tests.
- Covered discovery suffix boundaries, malformed candidate recovery, body-read
  timeouts, explicit-map precedence, ambiguous maps, first-save backups, and cache
  isolation between endpoints with identical map IDs.
- Inspected every decompressed entry in binary/source JARs: no former server
  hostname, server-specific policy class, or local state/config directory.
- Packaged client class loading without Mod Menu and API entrypoint/factory linkage
  with Mod Menu 20.0.3 passed. These checks do not initialize the Minecraft GUI.

The Minecraft GUI and real-server world transitions have not been exercised.
Mock tests and compilation do not establish those results. Servers that reuse a
dimension key for multiple worlds need additional server cooperation for reliable
automatic selection; a companion server plugin is not part of this release.

## Upgrade and rollback

Close Minecraft and replace the old JAR with RC.6, keeping the existing config.
To revert, close Minecraft and restore the old JAR. There is no automatic config
migration or deletion. Keep a copy of the config before editing server mappings.
