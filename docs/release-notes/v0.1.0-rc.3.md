# BlueMap Minimap 0.1.0 RC.3 — release candidate

This candidate targets **Minecraft 26.2, Java 25, and Fabric Loader 0.19.3+
in the 0.19 line**. It is a client-only mod; Fabric API is not required.
It is not a Minecraft 26.3 build.

## Changes since the published RC.1

- Bounded automatic BlueMap discovery for common same-domain deployments,
  plus reverse-DNS discovery for direct IPv4 connections and exact-host HTTP
  fallback on the standard BlueMap port for private IPv4 connections.
- Optional heading-up map rotation, north indicator, and X/Z coordinates.
- Japanese and English settings, immediate previews, and explanatory tooltips.
- Selectable HUD sizes of 40, 50, 60, 70, 80, 90, and 100 pixels; default 80.
- Configuration migration keeps north-up as the default.

## Validation on 2026-10-04

- Built from an isolated copy of the current RC.3 source with Java 25 using
  `gradlew.bat --no-daemon clean test build`.
- **107 tests passed; 0 failures, 0 errors, 0 skipped.**
- Tests cover configuration persistence at every selectable size, rotation and
  tile coverage, discovery, HTTP validation, cache behavior, SSE, and fallback.
- Binary metadata identifies `bluemap_minimap` 0.1.0-rc.3, client-only,
  Minecraft `~26.2`, Java `>=25`, Fabric Loader `>=0.19.3`.
- Archive paths and contents were checked for private configuration, credentials,
  and server-specific settings. No such content was found.
- Prior real-client acceptance evidence is for RC.2. **A fresh RC.3 real-client
  test has not been performed.** In particular, the new 40–100-pixel sizes have
  automated coverage but have not received a fresh visual acceptance check.

## Known limitations

- Terrain changes depend on BlueMap rendering updates.
- Unmapped or unavailable dimensions hide the minimap.
- Unusual BlueMap hostnames may need manual JSON configuration.
- Authenticated BlueMap endpoints, waypoints, pins, mobs, caves, death points,
  claims, a round mask, and a full-screen map are not supported.
- Nether/End travel has not received a production read-only real-client check.
- Outage fallback is tested with mocks; production BlueMap was not interrupted.
