# BlueMap Minimap for Moyo 0.1.0 RC.4

> **もよさば専用のクライアントMODです。一般のBlueMap導入サーバーでは使用できません。**
> Fabricクライアントの `mods` に入れるMODで、サーバープラグインではありません。
>
> **Moyo server only — not a general-purpose BlueMap addon.**
> This Fabric client mod is distributed for Moyo participants. Other servers are not supported.

Status: **RC.4 candidate source; JAR not published to GitHub Releases** (2026-10-05).
The existing GitHub RC.1 release remains available. RC.3 was distributed through Discord.

## Changes

- Built-in public Moyo endpoint and world mappings. A clean installation does not require JSON editing.
- Activation limited to `mc.moyokurumi.com`, optionally using the default port 25565.
  Other servers and single-player do not activate this build. No automatic endpoint or reverse-DNS discovery.
- Existing custom URLs, explicit mappings, other-server profiles, and display settings are preserved.
  Missing standard Moyo settings are supplied in memory without rewriting the existing JSON on load.
- The first settings save preserves the original JSON in `.pre-rc4.bak`, without replacing an existing backup.
- Strict map selection: missing or unsupported maps hide the HUD instead of guessing the overworld.
- Clear sessions on client world changes; prevent delayed metadata from restoring an obsolete session.
- Retry failed initialization and nearby tile fetches at 30-second intervals. Existing cached terrain can
  remain visible in the same session; cold starts require successful metadata retrieval.
- Retain RC.3 HUD sizes, rotation, compass, coordinates, and Japanese/English settings.

## Requirements

Minecraft Java Edition **26.2**, **Java 25**, **Fabric Loader 0.19.3** (tested).
Fabric API and other minimap/configuration mods are not required.
This build does not target Minecraft 26.3, Forge, or Bedrock.
