# BlueMap Minimap 0.1.0 RC.1

BlueMap Minimap is a standalone Fabric client mod that displays a server's
already-rendered BlueMap as a compact HUD minimap.

## Highlights

- One standalone mod JAR; Fabric API, Xaero, Map Link, Cloth Config, and Mod Menu
  are not required
- North-up BlueMap LOD 1 terrain centered on the local player
- Public same-map player heads and names
- BlueMap `tile`, `player`, and `marker` Server-Sent Events
- One-second player HTTP polling fallback while SSE is disconnected
- Per-server BlueMap URL and dimension mapping
- Configurable position, zoom, player visibility, names, and 80–240 pixel HUD
- Bounded memory/disk caches, conditional GET, atomic PNG replacement, and
  off-thread networking/image decoding
- 37 automated tests passing
- Isolated Minecraft 26.2 / Fabric Loader 0.19.3 / Java 25 E2E passed with only
  this mod JAR in the `mods` directory

## Known limitations

- BlueMap must render a changed tile before the change can appear.
- Dimensions without a mapped BlueMap map are hidden.
- Nether and End travel have not been exercised in the production read-only E2E.
- BlueMap-outage fallback has been verified with the mock suite rather than by
  stopping a production service.
- The map is north-up; rotation is not implemented.
- Waypoints, mobs, caves, death points, areas/claims, POIs, and a full-screen map
  are outside the v0.1 scope.
