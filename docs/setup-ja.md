# BlueMap Minimap 汎用版の導入・設定

Minecraft 26.3 / Fabric Loader 0.19.5以降 / Java 25向けRC.7試用版の手順です。
旧サーバー専用版には、この汎用設定画面はありません。
Minecraft 26.2にはRC.7を入れず、26.2対応版を使ってください。

## 導入

1. [GitHubのRC.7リリース](https://github.com/moyokurumi/bluemap-minimap/releases/tag/v0.1.0-rc.7)を開きます。
2. **Assets → `bluemap-minimap-0.1.0-rc.7.jar`**をダウンロードします。
   `-sources.jar`や`Source code`は開発者用で、導入には使いません。
3. Minecraftを終了し、旧版のJARを`mods`の外へ退避します。
4. Minecraft 26.3のFabric環境の`mods`へ、新しいJARを入れます。

同じMODを2つ同時に入れないでください。
設定ファイルを消す必要はありません。

このMOD単体にはFabric APIやCloth Configは不要です。Mod Menuは任意です。
Mod Menuを使う場合は[26.3対応の21.0.0](https://modrinth.com/mod/modmenu/version/21.0.0)と、
Mod Menu自身の依存MOD（対応するFabric API・Placeholder API）を入れます。

## 最初の接続

BlueMapを公開しているサーバーに参加します。一般的な公開URLと地図名であれば、
自動でミニマップが表示されます。すべての構成を自動認識できるわけではありません。

表示されない場合は、次の操作を一度行います。

1. **Esc → BlueMap Minimap 設定 → サーバー設定…** を開きます。
   Mod Menuの **Mods → BlueMap Minimap → 設定** からも開けます。
2. 接続中のMinecraftサーバーアドレスとワールドIDは自動入力されます。
3. サーバー管理者が公開しているBlueMapのルートURLを入力します。
   例: `https://map.example.com/`。ブラウザーURL末尾の`?…`や`#…`は除きます。
4. **地図一覧を取得**を押し、**地図**ボタンで現在のワールドに対応する地図を選びます。
5. **適用して戻る → 完了（保存）**を押します。

資源ワールドなどでは、移動後に同じ操作で地図を選びます。
設定はサーバーごとにPC内へ保存され、ほかの利用者へ送信されません。
別ワールドの地図が表示された場合は、自動選択を使わず正しい地図を指定してください。
複数ワールドに同じディメンションキーを使うサーバーは、このクライアントだけでは区別できません。

タイトル画面から設定する場合はサーバーアドレスを入力します。
自動検出だけを無効にする場合は、アドレスが空欄のままでも適用できます。

## 保存とキャンセル

サーバー設定の「適用して戻る」は、元の設定画面の編集中データへ反映します。
元の画面で「完了」またはEscを押すと保存します。「キャンセル」なら保存済み設定へ戻ります。
サーバー設定画面内のEsc・キャンセルは、適用前の入力を破棄します。

## 自動検出の範囲

接続先ホストのHTTPSと代表的な地図用サブドメイン、接続先と同じホストのHTTP 8100番を
少数の候補として確認します。ネット検索、ポート総当たり、LAN探索、逆引きDNSは行いません。
自動検出は設定画面で無効にできます。別ドメイン・特殊なポート・IPv6の場合はURLを指定してください。

BlueMap未導入・非公開のサーバー、ログイン必須の地図では利用できません。
地図を特定できない場合は非表示にし、設定を案内します。

## 旧版からの引き継ぎ

保存済みのURL・地図の対応・表示設定を引き継ぎます。新規インストールには特定サーバーの
情報は入っていません。旧版で保存されていなかった対応は必要に応じて選び直してください。
最初の保存前の設定は既存方式の`.pre-rc4.bak`へ退避し、既存バックアップを上書きしません。
